# Version History

| Transition     | Changes                                                                                                                                                                                                                                                                                                                             | Likely Issue Addressed                                                                                                                                                                                                                                                                                                                                                      |
|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 001 (baseline) | Core translation prompt with rules for accuracy, layout, placeholders, and proper nouns; mixed variable syntax (`{single}` and `{{double}}` braces); verbose formatting rules; three worked placeholder examples                                                                                                                    | Initial translation prompt                                                                                                                                                                                                                                                                                                                                                  |
| 001 to 002     | Unified all variables to `{{double}}` brace syntax; hardcoded document type to "academic regulation"; added ISO 639-1 clarification for language codes; added front-matter removal instruction; simplified formatting rules                                                                                                         | Template rendering failures from mixed variable naming; model misinterpreting bare language codes; YAML front matter from source documents bleeding into translations                                                                                                                                                                                                       |
| 002 to 003     | Stripped all bold Markdown formatting from prompt text; removed stale single-brace variable reference                                                                                                                                                                                                                               | Bold emphasis in prompt conflated with content formatting instructions, creating ambiguity                                                                                                                                                                                                                                                                                  |
| 003 to 004     | Required structured JSON output (language, title, translation); removed 3-step process scaffolding                                                                                                                                                                                                                                  | Application could not reliably parse raw text output; process section consumed tokens without measurable quality gain                                                                                                                                                                                                                                                       |
| 004 to 005     | Added term-precision rules (for example, "postgraduate" vs "doctoral", "professor" vs "lecturer"); restructured rules as `##` subheadings; required valid Markdown in output; removed placeholder examples                                                                                                                          | Model conflating semantically distinct academic terms in translation                                                                                                                                                                                                                                                                                                        |
| 005 to 006     | Major rewrite: added guiding principles ("Assume High Stakes", "Think Like a University Registrar", "When in Doubt, Do Not Invent"); added "Cardinal Rule: No Content Alteration" with three explicit DO NOT directives (omit, add, interpret); added 5-category terminology verification checklist; added semantic precision rules | Multiple production failures: content omission/addition, semantic drift with near-synonyms ("support" vs "encouragement"), formality degradation ("Code of Conduct" becoming "Operating Instructions"), institutional terms translated literally instead of mapped to established equivalents (for example, "Faculty of Arts" incorrectly becoming "Faculty of Philosophy") |
| 006 to 007     | No prompt change; added deterministic inference parameters (`temperature: 0`, `seed: 42`, `top_p: 0`, `top_k: 1`)                                                                                                                                                                                                                   | Run-to-run variability in translations; needed reproducible outputs for regression testing                                                                                                                                                                                                                                                                                  |
| 007 to 008     | Decoupled source document from prompt template; added `INPUT DATA` description; removed `source_content` variable                                                                                                                                                                                                                   | Architectural separation of stable instructions from variable document content; avoids "lost in the middle" effects with long documents; enables prompt caching independently of document content                                                                                                                                                                           |
